# 📚 Arisora Bookstore - Aplikasi Manajemen Toko Buku

Sistem informasi berbasis web interaktif untuk pengelolaan katalog buku, transaksi pemesanan, dan tracking status pengiriman barang di **Arisora Bookstore**.

## 📌 Deskripsi Project

Arisora Bookstore adalah aplikasi web yang dirancang untuk mempermudah operasional toko buku secara terintegrasi. Fitur-fitur utama aplikasi meliputi:

1. **Authentication & User System:** Halaman Login, Register, dan Reset Password.
2. **Dashboard Interactive:** Menampilkan ringkasan menu utama, greeting dinamis, serta Laporan Pemesanan & History Transaksi.
3. **Katalog & Stok Buku:** Pencarian buku, filter berdasarkan kategori, dan penambahan stok baru secara real-time.
4. **Checkout / Pemesanan:** Pilihan buku interaktif, kalkulasi total otomatis, serta pembuatan nomor *Delivery Order* (DO).
5. **Tracking Pengiriman:** Fitur pencarian dan pelacakan status pengiriman barang berdasarkan nomor DO.
